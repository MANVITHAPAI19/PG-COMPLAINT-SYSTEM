# PG Complaint System

## 📌 Project Description

The PG Complaint System is a web-based application designed to help PG
residents submit complaints and manage common accommodation-related issues.

The system provides a simple interface where users can register their
complaints and the complaint details can be handled through the backend.

## 🎯 Objective

The main objective of this project is to provide a simple digital platform
for managing PG complaints instead of relying on manual complaint handling.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
